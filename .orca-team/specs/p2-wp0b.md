WHAT THE SCRIPT DOES
1. Reads data/raw/bangladesh_dengue_large_dataset_onsite.xlsx read-only; exits non-zero without writing if its SHA-256 is
   not 24fac5430af369142fcb3b1f0bd1fb99ca4583c618f83336d5dee58a5ebef9b0.
2. For each supply, checks round_half_up(c × dengue_cases) == column on all 31,320 rows; exits non-zero if any row
   differs. Writes supply_ratios.json exactly as contracts §3 (constants, valid intervals, row_match).
3. Capacity per ward from 2016–2022 rows only; writes ward_capacity.json exactly as contracts §3 (method, fitted
   years, SHA, assumption text, total_beds, wards).
4. Deterministic: running it twice produces byte-identical files.
